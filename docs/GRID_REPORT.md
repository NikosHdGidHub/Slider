# Приёмка сеточных шаблонов «Атласа уроков»

Проверка выполнена в Chromium на production-сборке из ветки `feature/atlas-grid-v3`. Оба шаблона и методичка прошли импорт через интерфейс. Все пять слайдов прежнего примера после миграции совпали с исходными снимками попиксельно.

## Три контрольных задания

В тестовом профиле скачаны обе инструкции кнопками приложения. Для воспроизводимой приёмки взяты три эталонных JSON из скачанных файлов. Браузерный сценарий сравнивает их с файлами в репозитории и передаёт результат штатному импортёру. Возможность получить такой ответ с первой попытки в независимом чате ChatGPT или DeepSeek остаётся непроверенной.

## Что хранит формат 3

- **Главный шаблон.** Объект `master` содержит три именованные схемы. Для оформления новых слайдов предусмотрены встроенные образцы фонов и закреплённых объектов. Они доступны после экспорта и удаления исходной карточки из каталога.
- **Геометрия.** Общий модуль вычисляет полосы по весам, прямоугольники объединённых ячеек и внутренние отступы. В доступное пространство ячейки `area` вписывается прямоугольник 16:9. Структура внутри него использует собственные координаты 1280 × 720. Объекты свободного блока сохраняют локальную геометрию. При смене размеров области визуализатор применяет единый масштаб к координатам, тексту, изображениям и фигурам. [Сеточный движок](../src/grid.ts)
- **Содержимое.** Слайд владеет объектами, их порядком, заметками и необязательной структурой. `slot` задаёт размещение, `group` объединяет объекты для перемещения, `relation` связывает их по смыслу. У пары «изображение и подпись непосредственно под ним» связь создаётся автоматически. При отсутствии совместимого места объект получает `slot="tray"`. Его содержимое и прежняя привязка сохраняются. Неразмещённое доступно в редакторе и полном JSON. Публичная копия для показа содержит размещённые объекты.
- **Интерфейс.** Конструктор главного шаблона позволяет переключать три схемы. Конструктор структурного шаблона работает с одной сеткой. Редактор методички использует ту же геометрию для заполнения слотов, показа, миниатюр и возврата к свободному размещению. Колонтитулы получают общее значение из документа и локальное переопределение из слайда. [Конструктор](../src/GridDesigner.tsx) · [Панель размещения](../src/PlacementPanel.tsx) · [Визуализатор](../src/Stage.tsx)
- **Сохранение.** Существующая IndexedDB продолжает хранить документы и ревизии. Импорт прежней версии добавляет шаблон «По умолчанию». При первой замене этого шаблона запись обновлённого документа и резервной копии прежней композиции проходит в одной транзакции. «Сохранить как шаблон» дожидается записи методички, выбирает первые title, normal и end, назначает независимые идентификаторы и сохраняет карточку перед открытием конструктора. Конфликт записи останавливает преобразование. [Хранилище](../src/storage.ts)

## Две инструкции для ИИ

Инструкция из раздела «Шаблоны» описывает проектирование сетки и обёртку `format, kind, description, deck`. Инструкция из «Моих методичек» описывает создание урока, заполнение готовых слотов, работу с текстом, изображениями и векторной графикой. Обе включают действующие определения схемы, каталог типов, доступные стили и гарнитуры. Источником списка шаблонов служит каталог, доступный текущему пользователю в момент скачивания. Имена и описания пользовательских записей обозначены как данные. Публичные примеры инструкций в репозитории сформированы только по встроенному каталогу.

Валидатор проверяет поля, типы объектов, идентификаторы и ресурсы. Сеточный движок дополнительно проверяет покрытие ячеек, пересечения, полезную площадь и совместимость привязок. Тесты прогоняют примеры через эти же функции и сверяют снимки инструкций с результатом текущих генераторов. [Схема](../src/schema.ts) · [Генераторы](../src/instructions.ts) · [Инструкция для шаблонов](grid/template-instructions.txt) · [Инструкция для презентаций](examples/atlas-instructions.txt)

## Повторный запуск

Для локальных браузерных тестов нужны Node.js 24, Python с Playwright и Chromium. Базовую сборку выполняют без переменных подключения к Supabase.

```sh
npm ci
npm run build
node --test tests/*.test.mjs
python tests/browser.py
python tests/studio.py
ATLAS_GRID_CAPTURES=/tmp/atlas-grid python tests/grid_browser.py
```

Проверка шрифтов принимает пути к реальным файлам WOFF2, WOFF, TTF и OTF. Облачный сценарий запускается на отдельной сборке с тестовыми значениями из заголовка скрипта. [Проверки сетки](../tests/grid.test.mjs) · [Браузерная приёмка](../tests/grid_browser.py) · [Проверка шрифтов](../tests/fonts_browser.py) · [Облачный сценарий](../tests/cloud_browser.py)
