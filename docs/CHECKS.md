## Повторить локальные проверки

В каталоге проекта установите зависимости и выполните команды с Node.js 24.

```sh
npm ci
npm run build
node --test tests/*.test.mjs
```

Браузерный сценарий использует Python 3, Playwright и Chromium. Сначала соберите проект без клиентских переменных Supabase для проверки локального режима. Установите Playwright в виртуальное окружение Python и запустите следующий сценарий.

```sh
python -m pip install playwright
python -m playwright install chromium
python tests/browser.py
```

Скрипт создаёт временный HTTP-сервер, тестовые профили и JSON внутри временного каталога. Переменной CHROMIUM_PATH можно указать путь к системному Chromium. Практическая проверка публичных прав и отзыва ссылки описана в SUPABASE_SETUP.md.
