# Библиотеки и инструкции для ИИ

Ветка `style-new-v2` основана на `main` от коммита `e9a610f`.

## Библиотеки

«Мои методички» и «Шаблоны» используют одни карточки с реальными миниатюрами `Stage`. Галерея показывает обложки 16:9, каталог — небольшие обложки и колонки метаданных. В обоих видах доступны поиск, сортировка и меню карточки. Миниатюра методички открывает показ, миниатюра шаблона — предпросмотр. Создание, импорт, редактирование и операции с облаком доступны по контексту устройства и прав.

`Library`, `LessonLibrary`, `TemplateLibrary` и `library.css` объединяют компоновку, кнопки, оформление и статусы. Каждый статус опирается на происхождение, локальную и облачную ревизии. `ActionMenu` использует портал, открывается вверх при нехватке места снизу, закрывается по Escape и внешнему нажатию. Фокус возвращается на кнопку при выходе с клавиатуры. Иконочная кнопка общая с редактором. «Как читать рельеф» перенесена в «Руководство».

Режим и сортировка сохраняются раздельно для методичек, главных шаблонов и компоновок. Поиск, вкладка и прокрутка восстанавливаются при возвращении в библиотеку. Поиск учитывает кириллицу и латиницу без учёта регистра. На телефоне сохраняются меню просмотра, поиск и оба вида библиотеки. Создание, импорт в редактор и редактирование скрыты.

## Инструкции

Раньше общая инструкция включала весь доступный каталог, несвязанные стили и метаданные шрифтов. Теперь инструкция презентации получает только выбранный главный шаблон, а команда из меню «Создать» строит отдельную инструкцию главного шаблона или структурной компоновки.

`presentationInstructionsForTemplate` валидирует копию выбранной карточки и переиспользует подготовку образца `instantiate`. В инструкции остаются три схемы, геометрия слотов, фоны, колонтитулы, оформление, палитра и необходимые гарнитуры. `instructionSchema` находит зависимости из корня `Presentation` или `Template` по ссылкам в текущей формальной схеме. Автоматическая селекция сохраняет ограничения полей, включая редкие типы фигур, контуры и форматирование фрагментов.

Текстовые данные шаблона записаны отдельным блоком JSON. Исходные заметки и посторонние данные исключаются. Параметризованные или закрытые адреса и распознанные ключи вызывают сообщение с указанием, что поправить в шаблоне. Общедоступные растровые ресурсы встраиваются при наличии CORS. Повторяющиеся изображения встречаются в инструкции один раз, а итоговый JSON содержит настоящие data URL. Файл шрифта передаётся с оригинальными байтами и прежним ID, поэтому нужная гарнитура сохраняется при совпадении ID у разных шаблонов.

Контрольные тексты для воспроизведения — [презентация по шаблону «По умолчанию»](library/examples/presentation-default.txt), [новый главный шаблон](library/examples/new-main-template.txt) и [новая компоновка](library/examples/new-layout-template.txt).

## Размер инструкций

Измерение в байтах UTF-8. В старый и новый генераторы переданы одинаковые семь главных шаблонов и одна компоновка. Старый генератор презентаций выгружал весь набор за один раз, поэтому старое значение в строках презентаций совпадает. Старый генератор передавал метаданные пользовательских шрифтов. Новый сохраняет их исходные файлы.

| Сценарий | Раньше, байт | Теперь, байт | Сокращение |
| --- | ---: | ---: | ---: |
| Стандартный | 132 116 | 41 398 | 68,7% |
| Рамка и колонтитул | 132 116 | 45 298 | 65,7% |
| Разное оформление трёх схем | 132 116 | 43 511 | 67,1% |
| Сложная сетка с изображением | 132 116 | 48 509 | 63,3% |
| Фон, логотип, градиент и контур | 132 116 | 51 323 | 61,2% |
| Пользовательский шрифт | 132 116 | 217 743 | −64,8% |
| Локальная ревизия со своим шрифтом | 132 116 | 164 975 | −24,9% |
| Создание главного шаблона | 72 816 | 39 581 | 45,6% |
| Создание компоновки | 72 816 | 39 858 | 45,3% |

Формальная схема занимает 27 651 байт для презентации и 28 021 байт для шаблона. Геометрия выбранных схем занимает 381–724 байта. В примерах с изображениями словарь занимает 5 037–5 149 байт. Шрифты занимают 175 232 и 123 228 байт соответственно. Пустой основной пример шаблона занимает 1 946 байт, пример компоновки — 2 207 байт. Размер инструкции выбранного шаблона не меняется при добавлении посторонних карточек.

## Проверки

- Production-сборка Vite и TypeScript прошла. Vite сообщил о размере основного пакета больше 500 КБ.
- 16 тестов Node покрывают изоляцию, неизменность выбранного шаблона, шаблоны семи видов, точные файлы гарнитур, восстановление изображений, соответствие схеме и безопасные имена файлов.
- В Chromium проверены обе библиотеки, кнопки и меню, восстановление прокрутки и настроек, пустые состояния, поиск и сортировка, импорт и экспорт, предпросмотр, удаление, локальный офлайн-режим, базовые операции редактора, конструкторы, показ и синхронизация проектора.
- Проверены 1024×600, 1280×720, 1366×768, 1440×900, 1920×1080 и 2560×1440, а также 100%, 125% и 150% через настройки Chromium. Эмуляция телефона использовала мобильный User-Agent и сенсорное управление при 360×640, 390×844, 430×932 и 844×390.
- На локальном стенде с имитацией Supabase API проверены вход, статусы шаблонов, запись в облако, скачивание из видимой локальной ревизии без перечитывания каталога, встраивание внешнего изображения и сохранность публичной версии после удаления локальной копии.
- Дополнительный облачный сценарий из `c8a9b66` адаптирован к меню карточек и выполнен на текущей сборке. Проверены публикация, отказ записи, обновление, синхронизация между профилями, файлы и отзыв публичного доступа.
- QR-передача проверена архивным сценарием Playwright из `c8a9b66` и тестовой сборкой текущей ветки. Проверены вход с телефона, декодирование QR, получение публикации и отмена. Базовый коммит `e9a610f` удалил прежний каталог тестов. Новые проверки этой ветки находятся в `tests/`.

### Воспроизведение

Python Playwright использует системный Chromium или путь из `CHROMIUM_PATH`. Для повторения сравнения укажите путь к отдельной рабочей копии базового коммита.

```sh
npm ci
npm run build
node --test tests/*.test.mjs
python tests/library_browser.py
ATLAS_LIBRARY_CAPTURES=/tmp/atlas-library python tests/library_browser.py
node tests/measure-instructions.mjs /path/to/baseline
```

Для облачного стенда соберите отдельный каталог со значениями `VITE_SUPABASE_URL=https://atlas-test.supabase.co`, `VITE_SUPABASE_ANON_KEY=sb_publishable_fixture` и `VITE_ADMIN_UUID=00000000-0000-4000-8000-000000000001`. Запустите `python tests/library_browser.py --cloud-only --cloud-dist /path/to/cloud-dist`.

### Ограничения

Крупные файлы гарнитур и изображений могут превысить лимит ответа внешней модели. Выбран самодостаточный итоговый JSON, который хранит оригинальные ресурсы и открывается после удаления исходного шаблона. Публичный HTTPS-источник требует доступности для браузера и CORS. Экспорт изображения по закрытому адресу требует загрузки оригинала в шаблон.

Облачные проверки выполнены с имитацией API и тестовыми учётными данными. Проверки на реальном проекте Supabase, физических телефонах и при системном масштабировании Windows требуют отдельного стенда.
