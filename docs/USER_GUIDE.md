# Руководство преподавателя

## Начало работы
1. На опубликованном сайте нажмите «Войти» и введите почту и пароль владельца. На своём компьютере можно попробовать редактор на localhost без настройки облака.
2. Нажмите «Открыть пример», чтобы посмотреть короткое занятие о рельефе. Кнопка выхода из показа вернёт вас в библиотеку.
3. Для своего занятия нажмите «Создать методичку», введите название и нажмите «Создать». Откроется первый пустой слайд. Название можно изменить в верхней строке редактора.

## Подготовка слайдов
1. Кнопка «Слайд» добавляет страницу после текущей. Выбирайте страницы по миниатюрам слева. Справа находятся команды изменения порядка и удаления. При удалении последней страницы появится пустая.
2. Щёлкните по свободному месту слайда или выберите «Свойства слайда». Задайте цвет фона либо загрузите фоновое изображение. Его можно убрать или сбросить весь фон.
3. Нажмите «Добавить текст». Выберите объект и отредактируйте текст, цвет, размер и выравнивание справа. Перетащите объект мышью.
4. Нажмите «Изображение» и выберите PNG, JPEG, WebP или SVG. Перетащите картинку. Потяните за угловой маркер выделенного изображения, чтобы изменить размер с сохранением пропорций.
5. Выберите объект и нажмите «Удалить объект» или Delete. Набирайте методический текст в поле под слайдом. У каждой страницы свои заметки.
6. Следите за индикатором сохранения в верхней строке. Черновики сохраняются в этом браузере. Ошибка записи требует внимания: экспортируйте JSON до закрытия вкладки.

## Перенос и публикация
1. В верхнем меню «⋯» выберите «Экспортировать JSON». Вставленные с компьютера картинки включаются в файл. Для импортированных внешних изображений сохраняются HTTPS-ссылки. Чтобы встроить и их, сначала подготовьте урок к офлайн-показу.
2. Для восстановления откройте «Импорт JSON» в библиотеке, выберите файл либо вставьте JSON и нажмите «Импортировать». Просмотрите слайды и сообщения о пересечениях и шрифтах. «Открыть в редакторе» создаёт независимую локальную копию с новым идентификатором.
3. После входа в облачную учётную запись нажмите «Опубликовать» рядом с «Показать». Скопируйте ссылку. Вместе со слайдами публикуются заметки. После изменений нажмите «Обновить публикацию» для обновления по прежнему адресу.
4. В разделе «Опубликованные» можно открыть ссылку или снять материал с публикации. Удаление локальной методички через корзину в библиотеке требует подтверждения и сохраняет её облачную публикацию. Копии JSON, сохранённые посетителями ранее, остаются у них.

## Проведение занятия
1. Нажмите «Показать». В режиме преподавателя выбирайте слайды и читайте заметки. В режиме «Только слайды» переключайтесь стрелками.
2. Подключите проектор как второй дисплей. Нажмите кнопку отдельного окна, разрешите всплывающее окно и перенесите его на проектор. Нажмите F или дважды щёлкните для полного экрана. Переключайте слайды в основном окне. Проектор показывает только содержимое слайда.
3. Для занятия без интернета заранее откройте production-версию и выберите «⋯» → «Подготовить к офлайн-показу». Дождитесь сообщения об успешном сохранении всех файлов, отключите сеть и проверьте открытие методички. На этом устройстве продолжайте использовать тот же профиль браузера.
4. Для установки откройте меню браузера и выберите установку приложения или добавление на домашний экран. Очистка данных сайта и приватный режим могут удалить черновики. Периодически сохраняйте JSON отдельно.

## Шаблоны

В разделе «Шаблоны» выберите «Презентации» или «Компоновки». Нажмите на миниатюру для просмотра. Чтобы изменить встроенный вариант, нажмите «Редактировать копию». В пользовательских карточках доступны редактирование, переименование, копирование, импорт, экспорт и удаление.

Для главного шаблона откройте вкладку «Презентации» и нажмите «Создать шаблон». Переключатели над холстом выбирают титульную, обычную и завершающую схемы. В «Компоновках» та же команда открывает одну сетку формата 16:9. Добавьте строки и столбцы. Чтобы объединить ячейки, выберите первую, нажмите «Объединить ячейки» и щёлкните по противоположному углу прямоугольника. Перетащите разделитель или введите вес полосы. В инспекторе задайте назначение, фон, границу и отступы. Для рамки вокруг всего слайда достаточно одной ячейки с указанной толщиной и цветом границы.

Ячейка «Область слайда» определяет место под содержимое. В редакторе методички выберите «Режим области слайда» и укажите компоновку. Щёлкните по текстовой ячейке для ввода или по ячейке изображения для загрузки файла. Для изображения доступны вписывание, заполнение с обрезкой и точка фокуса. Значения колонтитулов можно задать для всей методички и отдельно для текущего слайда.

При переходе из свободного режима в структурный подтвердите перенос или отмените действие. Перенесённые объекты ждут в панели «Неразмещённое содержимое» своего слайда. Чтобы вернуть объект, выберите его и укажите «Размещение объекта». Обратное переключение в свободный режим сохраняет положение размещённых объектов. В разделе «Группы и связи» отметьте два и более объекта одного свободного блока, чтобы перемещать их вместе. Смысловая связь хранится отдельно от группы.

«Сменить главный шаблон» применяет оформление ко всей методичке. При первом переходе старой методички с шаблона «По умолчанию» приложение сохраняет в библиотеке копию «до смены шаблона». Для создания нового шаблона из урока нажмите «Сохранить как шаблон». Нужны слайды всех трёх ролей. Редактор возьмёт первый слайд каждой роли и сохранит независимый шаблон.

## Фон и слои

В главном шаблоне выберите титульную, обычную или завершающую схему, затем откройте «Фон». При загрузке PNG, JPEG или WebP по умолчанию сохраняется оригинал. Для уменьшения размера выберите оптимизацию. Яркость, размытие, масштаб, точку фокуса и способ заполнения можно изменить после загрузки.

В презентации настройка фона создаёт индивидуальное оформление слайда. Команда «Вернуть фон шаблона» восстанавливает оформление его роли. «Применить фон к схеме этой методички» обновляет образец и все слайды этой роли, использующие общий фон. Остальные методички сохраняют свои копии шаблона.

Панель «Нераспределённые элементы» показывает объекты вне холста. Выберите объект и укажите подходящий слот в списке размещения. В «Слоях» верхняя строка соответствует переднему плану. Перетащите строку для изменения порядка, нажмите на неё для выбора, щёлкните правой кнопкой для переименования, блокировки или скрытия.

Отмена и повтор доступны из шапки редактора и по Ctrl+Z и Ctrl+Shift+Z. На macOS используется Cmd. Вне полей ввода Ctrl/Cmd+C, X и V работают с внутренним буфером редактора. При копировании группы создаются новые идентификаторы группы и объектов. У ячейки сетки можно скопировать оформление и назначение. Вырезание настроек оставляет пустую ячейку тех же размеров.

## Текст и фигуры

Дважды щёлкните по слову на холсте и введите текст. Щелчок за пределами фрагмента или Ctrl+Enter завершает ввод. Для форматирования части фразы выделите её в текстовом поле инспектора, откройте «Абзацы и фрагменты» и нажмите «Выделить фрагмент». Измените гарнитуру, кегль, цвет или начертание. В этой же панели можно добавить абзац и список.

«Шрифты и общие стили» управляют именованными стилями документа. Изменение общего стиля обновляет связанные объекты. Панель самого объекта позволяет изменить отдельное свойство. Автоподгонка измеряет текст и оставляет предупреждение, если он не помещается даже при минимальном кегле. Сократите фразу или увеличьте рамку.

Кнопка «Фигура» добавляет карточку. В списке «Форма» переключите её на эллипс, звезду, стрелку или другую форму. Вариант «Свой контур» открывает узлы на холсте. Перетаскивайте узлы и ручки Безье. Заливка, градиент, тень, линия, отражения и поворот задаются в инспекторе. Введите подпись в поле «Текст» фигуры.

Загрузите шрифт до 4 МиБ через «Шрифты и общие стили». Просмотрите образец, затем выберите гарнитуру для блока, фрагмента или стиля. При публикации пользовательские шрифты входят в публичный файл презентации. Проверьте разрешение правообладателя.

## Получение презентации от ИИ

В «Моих методичках» нажмите «Скачать инструкцию для генерации презентации». Прикрепите файл в новый чат с моделью, укажите тему, возраст и при необходимости название шаблона. Полученный JSON откройте через «Импорт JSON». Для создания шаблона скачайте «Инструкцию для генерации шаблона» в разделе «Шаблоны», а ответ модели откройте через «Импорт шаблона». Перед сохранением проверьте предпросмотр.

## Мои файлы

Войдите в аккаунт преподавателя и откройте «Мои файлы». Загрузите PNG, JPEG, WebP, PDF, PPTX или JSON методички. Для SVG библиотека сохраняет проверенную растровую версию WebP. Редактируемые векторные фигуры по-прежнему можно импортировать в слайд через «Изображение». При повторной загрузке одинакового файла под другим именем сохраняется существующая карточка.

Выберите папку перед загрузкой. «Создать папку» создаёт пустую папку. В карточке можно переименовать, переместить или скачать файл. Поиск работает по названию, фильтры — по папке и типу. В карточке JSON нажмите «Импортировать», чтобы проверить слайды и открыть отдельную методичку. PDF и PPTX скачиваются для работы в соответствующем приложении.

Для вставки выберите «Выбрать из моих файлов» на панели редактора или «Фон из моих файлов» в настройках фона. Размер, обрезка и поворот сохраняются в конкретной методичке. Файлы PDF, PPTX и JSON доступны только владельцу. Изображения доступны по прямой ссылке. Команда «Убрать из каталога» скрывает карточку и сохраняет все действующие ссылки. Повторная загрузка тех же байтов возвращает карточку.

## Редактирование на другом устройстве

Войдите как преподаватель и нажмите карандаш в разделе «Опубликованные». На новом устройстве редактор создаст локальный черновик из публичной версии. В него входят слайды, фон, шрифты и заметки. Нераспределённые элементы хранятся только в полном исходном черновике.

После локального сохранения кнопка рядом с «Показать» отражает состояние урока. «Опубликовано» означает, что содержимое совпадает. «Обновить публикацию» отправляет изменения по прежней ссылке. После обновления с другого устройства нажмите «Синхронизовать», затем «Загрузить опубликованную версию». Редактор сохранит предыдущий черновик отдельной методичкой с пометкой «до синхронизации».

При выходе с изменениями можно опубликовать их, оставить только на устройстве или продолжить редактирование. При ошибке записи экспортируйте JSON для восстановления. Для занятия без сети заранее выберите «Подготовить к офлайн-показу» и дождитесь подтверждения. Эта команда проверяет контрольные суммы адресованных по хэшу изображений и сохраняет сами изображения и фон вместе с уроком.
