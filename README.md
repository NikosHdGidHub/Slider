# Атлас уроков

Редактор учебных презентаций для одного преподавателя. Ученики открывают опубликованное занятие по ссылке. Преподаватель управляет показом, читает заметки и выводит слайды в отдельное окно для проектора.

## Посмотреть готовую сборку

В архив включена собранная папка dist. Если установлен Python 3, можно открыть прототип на своём компьютере одной командой из распакованной папки.

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

Откройте http://localhost:8000/. Для подключения своего Supabase понадобится пересборка с настройками проекта.

## Первый запуск из исходников

Установите Node.js 24 LTS и распакуйте архив. Откройте терминал в каталоге с package.json.



```sh

npx npm-check-updates@latest
npx npm-check-updates@latest -u

npm install
npm run dev
```

Откройте адрес localhost, указанный Vite. Без параметров Supabase редактор работает на localhost и loopback-адресах как локальная мастерская. На размещённом сайте доступ к черновикам и редактору открывается после входа владельца. Публичный пример позволяет познакомиться с показом без аккаунта.

## Сборка и офлайн-режим

```sh
npm run build
npm run preview
```

Откройте указанный адрес preview, создайте или импортируйте методичку и в меню редактора выберите «Подготовить к офлайн-показу». У dev и preview обычно разные порты и отдельные библиотеки. Перенесите урок через JSON, если переходите с одного адреса на другой.
