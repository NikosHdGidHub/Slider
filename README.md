# Атлас уроков

Редактор учебных презентаций для одного преподавателя. Ученики открывают опубликованное занятие по ссылке. Преподаватель управляет показом, читает заметки и выводит слайды в отдельное окно для проектора.

## Шаблоны и презентации

В разделе «Шаблоны» преподаватель создаёт три схемы главного шаблона или одну структурную компоновку. В методичке можно назначить компоновку отдельному слайду, заполнить ячейки текстом и изображениями или разместить объекты свободно. Презентации прежних версий открываются с исходной композицией.

В «Моих методичках» и «Шаблонах» доступны галерея, компактный каталог, поиск и меню карточек. Инструкция для готовой презентации скачивается из меню конкретного главного шаблона. Инструкция для нового шаблона доступна в меню «Создать» на соответствующей вкладке. Оба вида JSON можно просмотреть перед импортом.

## Первый запуск из исходников

Установите Node.js 24 и выполните в каталоге с package.json следующие команды.

```sh
npm ci
npm run dev
```

Откройте адрес localhost, указанный Vite. Без параметров Supabase редактор работает на localhost и loopback-адресах как локальная мастерская. На размещённом сайте доступ к черновикам и редактору открывается после входа владельца. Публичный пример позволяет познакомиться с показом без аккаунта.

## Сборка и офлайн-режим

```sh
npm run build
npm run preview
```

Откройте указанный адрес preview, создайте или импортируйте методичку и в верхней строке редактора нажмите «Подготовить к офлайн-показу». У dev и preview обычно разные порты и отдельные библиотеки. Перенесите урок через JSON, если переходите с одного адреса на другой.
