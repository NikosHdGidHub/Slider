# СПОСОБНОСТИ

## 1. Пороверить актуальность

```sh
### Клонируем актуальный main (если нету локальной папки)

git clone -b main https://github.com/NikosHdGidHub/Slider.git

### Переходим в проект

cd Slider

### Проверяем последние изменения

git pull origin main

### Создаём локальную ветку dev + date time

git switch -c "dev-$(date +%Y-%m-%d_%H-%M-%S)"

### Проверяем результат

git branch
git branch -vv
git status
git log -1 --oneline
```

## 2. Выполнение поставленой задачи

- Прочитать Техническое Задание (Обычно прикреплённый текст или пользовательский промпт)
- Разбей задачу на логические этапы
- Приступить к выполнению задачи
- Сложные технические решения можешь принимать самостоятельно
- Если возникают спорные вопросы связанные с визуалом: Останавливайся, спрашивая у пользователя варианты реализации. Визуализируя миниатюрами HTML Варианты. (Пользователь должен понимать что выбирает и на что это повлияет)
- После каждого реализованого этапа выполнять:

```sh
git add .
git commit -m "Описание изменений"
```

## 3. Публикация

- Выполни для публикации всех изменений:

```sh
git add .
git commit -m "Описание финальной реализации"
git push -u origin HEAD
```

- Затем проверь:

```sh
git branch -a
git branch -vv
```
